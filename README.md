# Nonlinear Forecasting Models — Implementations in Python

This repository contains the notebooks developed for the **Nonlinear Forecasting Models** course.  
It includes time series forecasting techniques using ARIMA, SARIMA/SARIMAX, and Feedforward Neural Networks (FFNN) applied to different real-world datasets.

Each topic is implemented in a separate Jupyter Notebook (`.ipynb`).

---

## Notebooks

* `ARIMA_FRED.ipynb` — ARIMA forecasting using FRED economic data  
* `ARIMA_egg_price.ipynb` — ARIMA model applied to egg price forecasting  
* `ARIMA_temp.ipynb` — Temperature forecasting with ARIMA  
* `ARIMA_traffic.ipynb` — Traffic forecasting using ARIMA models  
* `FFNN_Fútbol.ipynb` — Forecasting football-related data using Feedforward Neural Networks  
* `Formula1_FFNN.ipynb` — FFNN model applied to Formula 1 data  
* `SARIMAX_Pasajeros_Avión.ipynb` — Airline passenger forecasting using SARIMAX  
* `SARIMA_F1.ipynb` — SARIMA forecasting on Formula 1 data  
* `SARIMA_MLB.ipynb` — SARIMA model applied to MLB data  

---

## Objective

Develop forecasting models for time series analysis using both statistical and neural network approaches, comparing their performance on different datasets.
